    Config snapshots

    A snapshot holds channels.json exactly as it is, with each push stream key, each SRT passphrase and each CENC key. The broadcaster keeps it on the box. You cannot download it. The broadcaster also takes one automatically before you delete a channel.

    Snapshots live in the same volume as your data. They protect you from a mistake. They do not protect you from the loss of the volume. Use a recovery archive for that.

    Config template

    A template holds no keys. Each push channel it creates gets a NEW stream key. Every encoder in the field still sends to the old key, and it stops. Give the new key to each encoder after you import.

    A pull source URL keeps its host and path. It loses the user name, the password and the query parameters. Type them in again before you start the channel. Imported channels arrive stopped.

    Recovery archives

    ArchiveAgeSizeState

    Always restore the newest archive you have. The restore command refuses to write over a volume that holds data. It also refuses an archive whose name does not match the service. Do not add --force to get past these two refusals unless you know what the volume holds. No archive holds a .env file — those live on the host, outside the volumes.
