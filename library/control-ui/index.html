Backup & restore

      
A config artifact cannot bring a title back. The media of a title lives in the data
        volume. No config file holds it. To rebuild this library, restore the recovery archive of the whole volume, or
        ingest the titles again from the original files.


      
Config snapshots (the title registry and its keys)

      
 

      
A snapshot holds the ingest settings of each title and the per-title keys. The library keeps it on
        the box. You cannot download it. A restore puts back the ingest settings of a title that is still here.

Config template (no secrets — safe to download)

      

      
A template lists the titles this library holds. It does not hold the per-title keys, the admin
        accounts, or the source path of each title. Use it as a list of the titles to ingest on a second site.

Always restore the newest archive you have. The restore command refuses to write over a
